Списки и циклы — Автоматизируем рутину

Компьютеры созданы для того, чтобы избавить человека от однообразной скучной работы. Если нужно отправить 10 000 писем или обработать миллион ценников — человек сойдёт с ума за полчаса, а Python выполнит эту задачу за сотые доли секунды. В этом уроке мы научимся объединять данные в списки и мгновенно обрабатывать их циклами!

01. Списки (Lists) — Органайзер для ваших данных

Представьте, что у вас в интернет-магазине 50 товаров. Создавать 50 отдельных переменных item1, item2, item3... — это путь к катастрофе.

Вместо этого в Python используется список (list) — упорядоченная коллекция, элементы которой заключаются в квадратные скобки [...] и разделяются запятыми.

python • lists_intro.py
# Список строковых названий:
fruits = ["Яблоко", "Банан", "Апельсин", "Киви"]

# Список чисел:
scores = [100, 85, 92, 74]

print(fruits)
print("Количество фруктов в корзине:", len(fruits))
Результат в терминале:
['Яблоко', 'Банан', 'Апельсин', 'Киви'] Количество фруктов в корзине: 4

02. Индексация: Почему всё начинается с нуля?

Каждый элемент списка занимает строго своё место, которое называется индексом.

Аналогия: Смещение от начала линейки
В повседневной жизни мы считаем: 1-й, 2-й, 3-й. Но в архитектуре компьютеров индекс — это смещение в байтах от начала списка в памяти. Самый первый элемент лежит прямо у старта, поэтому его смещение равно 0!
python • indexing_magic.py
items = ["Меч", "Щит", "Зелье"]

print(items[0])   # 'Меч'   (первый элемент!)
print(items[1])   # 'Щит'   (второй элемент)

# Супер-способность Python: отрицательные индексы с конца!
print(items[-1])  # 'Зелье' (самый последний элемент!)
🚨
Ошибка IndexError: list index out of range

Если в списке 3 элемента (с индексами 0, 1, 2), а вы попытаетесь обратиться к items[3] или items[99], Python не станет гадать и выбросит исключение IndexError: «Такого номера в списке не существует!».

03. Цикл for: Перебор элементов в один миг

Цикл for в Python создан для идеального перебора элементов любой коллекции. Его синтаксис на естественном языке звучит так: «Для каждого элемента в списке — сделай следующее действие».

python • for_loop.py
cart = ["Ноутбук", "Наушники", "Мышь"]

for product in cart:
    print(f"📦 Отправляем со склада товар: {product}")

print("✅ Все заказы упакованы!")
Результат в терминале:
📦 Отправляем со склада товар: Ноутбук 📦 Отправляем со склада товар: Наушники 📦 Отправляем со склада товар: Мышь ✅ Все заказы упакованы!

04. Генератор range(): Как повторить действие 100 раз

Что если у вас нет списка, а вам нужно просто повторить команду 5 раз подряд? Вручную писать [0, 1, 2, 3, 4] не нужно — для этого есть встроенная функция range().

python • range_generator.py
# range(5) сгенерирует числа от 0 до 4 (5 НЕ включается!):
for i in range(3):
    print(f"Итерация №{i}")

# range(start, stop, step) — с 1 до 10 с шагом 2:
for n in range(1, 7, 2):
    print("Нечётное:", n)
Результат в терминале:
Итерация №0 Итерация №1 Итерация №2 Нечётное: 1 Нечётное: 3 Нечётное: 5

05. Цикл while: Повторяем, пока условие истинно

Если цикл for используется, когда мы знаем диапазон или перебираем список, то цикл while (пока) применяется тогда, когда неизвестно, сколько повторений потребуется заранее (например, пока у босса в игре не закончатся жизни).

python • countdown_while.py
timer = 3

while timer > 0:
    print(f"До старта: {timer}...")
    timer = timer - 1  # Обязательно уменьшаем таймер!

print("🚀 Поехали!")
Результат в терминале:
До старта: 3... До старта: 2... До старта: 1... 🚀 Поехали!
💀
Опасность бесконечного цикла (Infinite Loop)

Если в теле while забыть изменить условие (например, убрать строчку timer = timer - 1), переменная timer навсегда останется больше 0, и программа будет бесконечно крутить цикл, загружая процессор на 100%. Если ваш скрипт случайно завис — нажмите Ctrl + C в терминале, чтобы экстренно остановить его!
