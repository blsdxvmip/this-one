Ветвления и логика — Компьютер принимает решения

До сих пор наши программы были похожи на поезд, несущийся по прямым рельсам строго сверху вниз. Но настоящий интеллект начинается там, где появляется выбор! В этом уроке вы научите программу анализировать условия, выбирать правильный путь с помощью if / elif / else и освоите священное правило отступов в 4 пробела.

01. Развилка на дороге: Конструкция if / elif / else

Каждый день мы принимаем десятки решений: «Если идёт дождь — беру зонт. Иначе, если светит солнце — надеваю очки. Иначе — просто иду гулять».

В Python эта логика записывается тремя ключевыми словами:

  • if (если) — проверяет первое условие. Если оно истинно (True), выполняется связанный блок кода.
  • elif (сокращение от «else if», ещё если) — проверяется только тогда, когда предыдущие условия оказались ложными (False).
  • else (иначе) — выполняется в самом конце, если вообще ни одно из условий выше не сработало.
python • weather_branching.py
temperature = 24

if temperature > 25:
    print("Жаркий денёк! Включаем кондиционер ❄️")
elif temperature >= 15:
    print("Идеальная погода для прогулки в парке! 🌿")
else:
    print("Прохладно! Не забудь надеть куртку 🧥")
Результат в терминале:
Идеальная погода для прогулки в парке! 🌿

02. Отступы (4 пробела) — Священный закон Python

В других языках (JavaScript, C++, Java) блоки кода оборачиваются в фигурные скобки { ... }. Гвидо ван Россум счёл это лишним визуальным шумом.

В Python вложенность команд определяется строго отступами. Всё, что сдвинуто вправо относительно if, принадлежит этому условию. Как только отступ исчезает — блок закончен.

Аналогия: Подчинение в оглавлении книги
Представьте оглавление: есть «Глава 1», а чуть правее с отступом идут «Параграф 1.1» и «Параграф 1.2». Вы сразу видите глазами, что параграфы подчиняются главе. В Python точно так же: двоеточие (:) в конце строки говорит «внимание, сейчас будет блок!», а последующие 4 пробела показывают, какие именно команды в этот блок входят.
⚠️
Ошибка IndentationError — как её не допустить:

Стандартом в Python считаются ровно 4 пробела (или одно нажатие клавиши Tab, если редактор автоматически заменяет его на пробелы). Никогда не смешивайте настоящие табы и пробелы в одном файле!

03. Операторы сравнения: Спрашиваем компьютер

Любое условие в Python вычисляется либо в True (правда), либо в False (ложь). Для этого используются операторы:

python • comparison_operators.py
x = 10
y = 20

print(x == y)  # False (x РАВЕН y?)
print(x != y)  # True  (x НЕ РАВЕН y?)
print(x < y)   # True  (x МЕНЬШЕ y?)
print(x > y)   # False (x БОЛЬШЕ y?)
print(x <= 10) # True  (x МЕНЬШЕ ИЛИ РАВЕН 10?)
🚨
Самая частая ошибка новичков: = против ==

Одиночный знак равно = — это присваивание (мы кладём значение в коробку: score = 10).
Двойной знак равно == — это вопрос / сравнение (мы спрашиваем: if score == 10: «Правда ли, что набрано 10 очков?»).

04. Сложные условия: and, or, not

В реальной жизни условия часто комбинируются: чтобы получить права, вам должно быть 18 лет И вы должны сдать экзамен.

python • logical_operators.py
age = 20
has_passed_exam = True

# 1. and (И) — истинно ТОЛЬКО если ОБА условия истинны
if age >= 18 and has_passed_exam:
    print("Поздравляем с получением водительских прав! 🚗")

# 2. or (ИЛИ) — истинно, если ХОТЯ БЫ ОДНО условие истинно
is_admin = False
is_vip_guest = True

if is_admin or is_vip_guest:
    print("Доступ в закрытый лаундж открыт! 🍸")

# 3. not (НЕ) — переворачивает истину на ложь, и наоборот
is_game_paused = False
if not is_game_paused:
    print("Игра продолжается в штатном режиме.")
