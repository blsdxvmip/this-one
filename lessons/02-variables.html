Переменные и типы данных — Память программы

Если в первом уроке мы научили программу говорить, то сейчас мы подарим ей память! Вы разберётесь, как компьютер сохраняет имена, числа и логические состояния, как спросить пользователя о чём угодно с помощью input() и как собирать красивые сообщения с помощью современных f-строк.

01. Что такое переменная? Метафора подписанной коробки

В процессе работы программе постоянно нужно что-то помнить: сколько жизней осталось у игрока, как зовут пользователя, какой баланс на карте. Для этого в оперативной памяти выделяется кусочек пространства, которому дают имя.

Аналогия: Переменная — это коробка с ярлыком
Представьте картонную коробку, на которой маркером написано слово player_name. Внутрь этой коробки вы кладёте листок со словом "Артур". Каждый раз, когда вы в коде обратитесь к player_name, Python заглянет в эту коробку и достанет оттуда "Артур". Если позже вы положите туда "Мерлин", старое значение исчезнет, а коробка теперь хранит новое!

В Python создание переменной выглядит предельно просто с помощью знака равно = (он называется оператором присваивания):

python • variables_intro.py
user_name = "Алиса"
user_score = 150

print(user_name)
print(user_score)
Результат в терминале:
Алиса 150
📌
Правила хорошего тона для имён переменных:

Имена переменных пишутся маленькими латинскими буквами, а слова разделяются нижним подчеркиванием (этот стиль называется snake_case, например: hero_health, max_speed). Имя не может начинаться с цифры и не должно содержать пробелов.

02. Четыре кита: Базовые типы данных

В коробку можно положить разные вещи: обувь, книгу или воду. Компьютер должен точно знать, что именно лежит в переменной, чтобы понимать, какие операции с ней разрешены (например, числа можно складывать, а строки — объединять).

В Python есть 4 главных базовых типа данных:

python • data_types.py
# 1. int (Integer) — целые числа
age = 25
level = 1

# 2. float (Floating point) — дробные числа (с плавающей точкой)
price = 19.99
pi = 3.14159

# 3. str (String) — строки, любой текст в кавычках
title = "Мастер Python"

# 4. bool (Boolean) — логический тип: только True (Истина) или False (Ложь)
is_game_over = False
has_key = True

Узнать тип любой переменной в любой момент можно с помощью команды type(x): 

print(type(100))      # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("Привет")) # <class 'str'>
print(type(True))     # <class 'bool'>

03. Ввод пользователя: Функция input() и превращение типов

Программы становятся по-настоящему полезными, когда они умеют слушать человека. Функция input() ставит программу на паузу и ждет, пока пользователь напечатает текст в консоли и нажмет Enter.

🚨
Самый коварный капкан новичков: input() ВСЕГДА строка!

Даже если пользователь введет в консоли число 10, функция input() вернет не число, а строку "10" (символ в кавычках). Если сложить две такие строки: "10" + "5", Python не посчитает сумму 15, а «склеит» текст в "105"!

Чтобы превратить текст в настоящее число для математических вычислений, используют функции преобразования:

  • int("42") — превращает строку в целое число 42
  • float("9.99") — превращает строку в дробное число 9.99
  • str(100) — превращает число обратно в строку "100"
python • input_sum.py
# Спрашиваем число и сразу оборачиваем в int():
age_str = input("Сколько вам лет? ")
age = int(age_str)

next_year_age = age + 1
print("В следующем году вам исполнится:", next_year_age)

04. Современные f-строки: Магия форматирования текста

Раньше программистам приходилось мучиться со сложением строк через плюсики:
print("Привет, " + name + "! Тебе уже " + str(age) + " лет.") — это длинно, легко забыть пробел или получить ошибку из-за типа.

Начиная с Python 3.6, появилась великолепная конструкция — f-строки (formatted strings). Вы просто ставите букву f перед открывающей кавычкой, а внутри текста любые переменные и даже вычисления помещаете прямо в фигурные скобки {...}!

python • f_strings_magic.py
hero_name = "Нео"
level = 7
hp = 84.5

# Обратите внимание на букву 'f' перед кавычкой:
status_message = f"Герой: {hero_name} | Уровень: {level} | Здоровье: {hp} HP"
print(status_message)

# Внутри фигурных скобок можно даже производить вычисления:
print(f"В следующем раунде уровень будет: {level + 1}")
Результат в терминале:
Герой: Нео | Уровень: 7 | Здоровье: 84.5 HP В следующем раунде уровень будет: 8

Напишите программу оформления заказа в кафе:
