Функции — Собираем свой инструментарий

Поздравляем с выходом в финал курса! Настоящий программист отличается от новичка тем, что не пишет один и тот же код дважды. Пришло время познакомиться с величайшей суперсилой разработки — пользовательскими функциями, научиться упаковывать сложную логику в компактные блоки и раз навсегда понять, чем print() отличается от return.

01. Зачем нужны функции? Принцип DRY

Представьте, что вам в 10 разных местах интернет-магазина нужно рассчитывать стоимость доставки: учитывать вес, расстояние и персональную скидку. Если скопировать 15 строк вычислений 10 раз — получится 150 строк кода. А если завтра правила доставки изменятся? Вам придется исправлять ошибку во всех 10 местах!

В программировании есть главное золотое правило: DRY — Don't Repeat Yourself («Не повторяйся!»).

Аналогия: Функция — это кухонный комбайн
Вам не нужно каждый раз изобретать способ нарезки моркови ножом. Вы покупаете кухонный комбайн (объявляете функцию), нажимаете одну кнопку (вызываете функцию) — и комбайн выдаёт нарезанные овощи. Вы можете использовать его бесконечное количество раз в любой день!

02. Ключевое слово def: Создаём свою первую команду

Функция создается с помощью слова def (сокращение от англ. define — «определить»). Затем пишется имя функции, круглые скобки (куда передаются входные данные) и двоеточие.

python • custom_greeting.py
# 1. Объявление (создание) функции:
def greet_user(name):
    print(f"✨ Привет, {name}! Добро пожаловать в Академию Python.")

# 2. Вызов функции для разных людей:
greet_user("Алиса")
greet_user("Борис")
greet_user("Виктория")
Результат в терминале:
✨ Привет, Алиса! Добро пожаловать в Академию Python. ✨ Привет, Борис! Добро пожаловать в Академию Python. ✨ Привет, Виктория! Добро пожаловать в Академию Python.
💡
Параметры vs Аргументы — в чём разница?

Параметр — это переменная в круглых скобках при создании функции (например, name).
Аргумент — это конкретное реальное значение, которое вы передаете внутрь при вызове (например, "Алиса").

03. Великая битва: print() против return

Это главная концептуальная ступень, на которой спотыкается каждый второй начинающий. Поймите её сейчас — и вы будете на голову опережать большинство самоучек!

Аналогия: Официант и Повар
Представьте ресторан:
• Команда print() — это официант, который громко выкрикивает в зал: «Блюдо готово!». Люди в зале услышали (увидели текст на экране), но сам ресторан съесть этот выкрик не может — звуковые волны улетучились.
• Команда return — это повар, который ставит готовое горячее блюдо на стойку выдачи. Теперь это блюдо можно положить в контейнер (сохранить в переменную), добавить к другому блюду (сложить числа) или отправить курьером (передать в другую функцию)!
python • return_vs_print.py
# Функция С ВОЗВРАТОМ ЗНАЧЕНИЯ (return):
def calc_discount(price, percent):
    discount_amount = price * (percent / 100)
    final_price = price - discount_amount
    return final_price  # Отдаём результат наружу!

# Мы сохраняем возвращённый результат в переменную и продолжаем работать:
total = calc_discount(1000, 15)
print(f"Итого к оплате: {total} ₽")

# Можно использовать в дальнейших формулах:
two_items = total * 2
print(f"За два таких товара: {two_items} ₽")
Результат в терминале:
Итого к оплате: 850.0 ₽ За два таких товара: 1700.0 ₽
🚨
Что будет, если забыть return?

Если в функции нет слова return, Python автоматически вернет служебное пустое значение None. Если попытаться умножить результат такой функции на 2: result * 2, программа упадет с ошибкой TypeError: unsupported operand type for NoneType!
