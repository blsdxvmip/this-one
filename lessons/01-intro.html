Старт в Python — Первая строка кода

Добро пожаловать в мир программирования! В этом уроке вы узнаете, почему Python стал самым популярным языком планеты, как машина понимает написанный вами текст, напишете свою первую работающую команду и научитесь избегать ловушек, в которые попадают 90% новичков.

01. Зачем нужен Python?

Представьте язык, синтаксис которого читается почти как обычный английский текст. Без сотен непонятных знаков препинания, точек с запятой на каждом шагу и громоздких правил. Это и есть Python (Питон).

Созданный голландским программистом Гвидо ван Россумом и названный в честь комедийного шоу «Монти Пайтон», этот язык проектировался с одной главной целью: человекочитаемость и простота для человека.

Аналогия из жизни: Почему Python повсюду?
Если бы языки программирования были автомобилями, то язык C/C++ был бы болидом «Формулы-1» (супербыстрый, но если повернуть руль без шлема — авария), а Python — это современный комфортный электрокар с автопилотом. Вы просто задаете пункт назначения, а умные системы под капотом берут всю рутину на себя.

Сегодня на Python создают:

  • Искусственный интеллект и Data Science: от нейросетей OpenAI и ChatGPT до анализа астрономических снимков NASA.
  • Веб-сервисы и серверы: YouTube, Instagram, Spotify, Dropbox построены на Python.
  • Автоматизацию и скрипты: миллионы рутинных задач (скачивание файлов, разбор отчетов в Excel, боты в Telegram) решаются десятком строк.

02. Как компьютер понимает ваш код?

Процессор вашего компьютера не умеет читать слова. Его физическая природа — это миллиарды микроскопических транзисторов, которые оперируют только двумя состояниями: есть ток (1) или нет тока (0). Этот язык нулей и единиц называется машинным кодом.

Если бы программистам приходилось писать программы в нулях и единицах, написание простого калькулятора занимало бы месяцы. Поэтому люди создали интерпретатор Python.

💡
Интерпретатор — ваш личный переводчик-синхронист

Интерпретатор Python — это специальная программа. Она берёт написанный вами файл со строками понятного текста, построчно читает его сверху вниз, моментально переводит каждую команду в понятные процессору машинные инструкции и тут же передает процессору на выполнение.

03. Функция print() — Ваш первый голос в терминале

Чтобы программа смогла нам что-то сообщить, в Python существует встроенная команда (функция) print() (от англ. «печать» или «вывод»).

Всё, что вы положите внутрь круглых скобок, программа отобразит на экране (в окне терминала или консоли).

python • lesson_1_hello.py
print("Привет, Мир!")
print("Я изучаю Python — это захватывающе!")
print(42)
Результат в терминале:
Привет, Мир! Я изучаю Python — это захватывающе! 42

Строки: почему текст нужно оборачивать в кавычки?

Обратите внимание: слова "Привет, Мир!" заключены в двойные кавычки. В Python любой текст называется строкой (string).

Кавычки говорят интерпретатору: «Эй, не пытайся искать здесь встроенную команду или системную формулу! Это просто буквы для человека, выведи их как есть!». Если вы передаете число (например, 42), кавычки не обязательны, ведь машина отлично понимает числа математически.

✨
Одинарные или двойные кавычки?

В Python нет разницы между 'Привет' и "Привет". Главное правило — пара должна совпадать: открыли двойной кавычкой — закрывайте двойной! Если внутри текста вам нужна апостроф (например: "Don't panic"), просто оберните всю фразу в двойные кавычки.

04. Комментарии (#) — Заметки для себя и команды

В коде часто нужно оставить подсказку для себя на будущее или для своих коллег. В Python для этого используется символ решетки #.

Всё, что написано в строке после знака #, полностью игнорируется интерпретатором.

python • comments_demo.py
# Это комментарий: программа его не читает
print("Код выполняется!")  # Комментарий можно писать и в конце строки

# print("Эта строчка временно отключена и не сработает")
Результат:
Код выполняется!

05. Частые ошибки новичков: Не бойтесь красного текста!

Ошибки в программировании — это не неудача, а самый ценный инструмент обучения. Python очень вежлив: когда он натыкается на проблему, он прямо указывает номер строки и причину остановки.

⚠️
Ловушка №1: Регистр букв имеет значение!

Для Python слова print, Print и PRINT — это три абсолютно разные вещи. Все стандартные команды пишутся исключительно маленькими (строчными) буквами. Если написать Print("Привет"), Python выдаст ошибку: NameError: name 'Print' is not defined.

🚨
Ловушка №2: Потерянная скобка или кавычка (SyntaxError)

Если вы открыли скобку или кавычку, но забыли закрыть её в конце — интерпретатор запутается и выдаст SyntaxError: unterminated string literal. Скобки и кавычки в программировании всегда ходят парами, как перчатки!
