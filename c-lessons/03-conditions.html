Урок 3: Ветвления и логика в Си

Программа, выполняющая инструкции строго по прямой линии сверху вниз, способна лишь на простейшие расчеты. Настоящая мощь программного обеспечения начинается тогда, когда код может принимать решения. В этом уроке мы разберем, как устроен выбор пути в Си, почему число 0 священно для процессора и как работает оператор switch.

01. Как Си понимает «Правду» и «Ложь»?

В большинстве современных языков есть явный логический тип данных: True и False. Но когда в начале 1970-х создавался язык Си, разработчики стремились к максимальной экономии каждого транзистора:

⚖️
Золотое правило логики в Си: 0 — это ложь, всё остальное — правда

В классическом Си нет встроенного типа boolean (он был добавлен лишь в стандарте C99 в виде макроса в <stdbool.h>). Процессор трактует числа так:

  • Число 0: строго означает ЛОЖЬ (False).
  • Любое ненулевое число (1, -5, 42, 100): означает ИСТИНУ (True).

Когда в Си выполняется операция сравнения, например 5 > 2, процессор вычисляет не абстрактное слово, а возвращает обычное целое число 1. Если сравнение неверно (2 > 5), результатом будет число 0. 

if (0) {
    // Этот блок НЕ выполнится никогда, потому что 0 - это ложь
}

if (42) {
    // Этот блок выполнится ВСЕГДА, потому что 42 != 0 (истина)
}

02. Конструкция if / else if / else

Синтаксис ветвления в Си требует обязательного заключения проверяемого выражения в круглые скобки (условие):

c • temperature.c
#include <stdio.h>

int main(void) {
    int temp;
    printf("Введите температуру воды (°C): ");
    scanf("%d", &temp);

    if (temp >= 100) {
        printf("Вода закипела и превратилась в пар!\n");
    } else if (temp <= 0) {
        printf("Вода замерзла в лед!\n");
    } else {
        printf("Вода находится в жидком агрегатном состоянии.\n");
    }

    return 0;
}
🚨
Классическая ловушка Си: = вместо ==

Одна из самых коварных ошибок в истории программирования: 

if (x = 5) { /* ОШИБКА! Это присваивание, а не сравнение! */ }

Знак одиночного = присваивает переменной x значение 5. А так как результат операции равен числу 5 (а 5 — это не ноль, то есть истина), условие внутри if сработает всегда, а значение переменной будет безнадежно испорчено!

Для сравнения на равенство всегда пишите двойное ==: if (x == 5).

03. Логические связки: &&, ||, !

Когда для принятия решения нужно учесть несколько факторов, используются логические операторы:

Оператор Название Поведение Пример на Си
&& Логическое И (AND) Истина только если оба операнда истинны age >= 18 && has_ticket == 1
|| Логическое ИЛИ (OR) Истина, если хотя бы один операнд истинен is_admin == 1 || is_author == 1
! Логическое НЕ (NOT) Инвертирует значение: 0 превращает в 1, любое не 0 — в 0 !is_blocked
⚡
Короткое замыкание (Short-circuit evaluation)

Си экономит вычисления процессора:

  • В A && B: если A ложно (равно 0), то всё выражение гарантированно ложно. Процессор даже не будет вычислять B.
  • В A || B: если A истинно, то всё выражение гарантированно истинно. Вторая часть B просто игнорируется.

04. Оператор switch / case и опасность забытого break

Когда нужно сравнить одну переменную со множеством точных целочисленных значений (или символов char), длинная цепочка if ... else if ... else if выглядит громоздко. В Си для этого создан switch:

c • menu.c
#include <stdio.h>

int main(void) {
    int command = 2;

    switch (command) {
        case 1:
            printf("Запуск игры\n");
            break; // Выход из switch!
        case 2:
            printf("Настройки звука\n");
            break;
        case 3:
            printf("Выход из приложения\n");
            break;
        default:
            printf("Неизвестная команда!\n");
            break;
    }

    return 0;
}
⚠️
Проваливание (Fall-Through): Почему break обязателен?

Метка case в Си — это всего лишь закладка в книге, куда процессор совершает мгновенный переход (jump). Если в конце секции case не поставить команду break;, процессор не остановится! Он просто провалится дальше и выполнит код всех следующих case подряд, даже если их условия не совпали!
