Урок 5: Функции и основы указателей

Поздравляем с выходом на финишную прямую теоретического курса! В этом уроке мы разберем главный супер-инструмент языка Си — указатели (pointers). Указатели часто пугают новичков, но на самом деле их концепция предельно проста и наглядна. Мы разберем, зачем нужны прототипы функций, почему значения копируются при вызове и как указатели позволяют управлять памятью напрямую.

01. Функции и загадка прототипов (Function Prototypes)

В Си программа компилируется компилятором сверху вниз в один проход. Представьте, что вы написали такой код: 

#include <stdio.h>

int main(void) {
    int res = calculate_sum(10, 20); // ОШИБКА: компилятор еще не знает о calculate_sum!
    printf("%d\n", res);
    return 0;
}

int calculate_sum(int a, int b) {
    return a + b;
}

Когда компилятор дойдет до вызова calculate_sum внутри main, он выдаст предупреждение или ошибку: «implicit declaration of function». Ведь он ещё не прочитал строки ниже!

📜
Прототип — это паспорт функции перед ее телом

Чтобы код был аккуратным, а функция main оставалась вверху файла как оглавление книги, используют прототипы функций (forward declarations).

Прототип — это просто заголовок функции с точкой с запятой в конце, помещенный до функции main: 

int calculate_sum(int a, int b); // Прототип: обещание компилятору

Компилятор видит прототип и говорит: «Отлично! Я знаю, что функция принимает два целых числа и вернет int. Продолжаю сборку!». А саму реализацию вы спокойно размещаете внизу.

02. Передача аргументов по значению: Почему переменная не меняется?

Рассмотрим классическую попытку новичка увеличить число в функции:

c • pass_by_value.c
#include <stdio.h>

void add_ten(int num) {
    num = num + 10; // Изменяется только ЛОКАЛЬНАЯ копия в стеке!
}

int main(void) {
    int score = 50;
    add_ten(score);
    printf("Счет: %d\n", score); // На экране по-прежнему 50!
    return 0;
}

В Си параметры функций передаются строго по значению (pass-by-value). Это значит, что значение 50 было скопировано в новую, отдельную ячейку памяти аргумента num. Когда функция add_ten завершилась, эта временная ячейка была уничтожена. Переменная score в main осталась нетронутой!

Как же заставить функцию изменить оригинальную переменную? Передать её адрес с помощью указателя!

03. Указатели: Адрес против Содержимого

Что такое указатель? Снимите ореол таинственности:

🎯
Указатель — это просто переменная, хранящая числовой адрес другой ячейки памяти

Обычная переменная int x = 42; хранит число 42.
Указатель int *p = &x; хранит числовой адрес — например, 0x7ffd510.

Аналогия: Записка с адресом банковской ячейки
Представьте, что у вас в сейфе лежат золотые слитки (переменная x). Вместо того чтобы носить тяжелый сейф с собой, вы берете клочок бумаги и записываете на нем: «Банк ВТБ, сейф № 402» (это указатель p). Вы можете передать эту записку любому доверенному лицу (функции), и этот человек придет прямо к сейфу № 402 и положит туда новое золото!

Два главных оператора при работе с указателями:

  • & (Взятие адреса): «Скажи мне, по какому адресу в RAM лежит эта переменная?» (например, &x).
  • * (Разыменование): «Иди по сохраненному адресу и возьми то, что там лежит!» (например, *ptr = 100;).

Правильный код с изменением через указатель:

c • pass_by_pointer.c
#include <stdio.h>

// Функция принимает УКАЗАТЕЛЬ на int (адрес ячейки памяти)
void add_ten_real(int *ptr) {
    *ptr = *ptr + 10; // Разыменование: идем по адресу и прибавляем 10 к оригиналу!
}

int main(void) {
    int score = 50;
    add_ten_real(&score); // Передаем АДРЕС переменной score через &
    printf("Обновленный счет: %d\n", score); // Выведет: 60!
    return 0;
}
Результат:
Обновленный счет: 60

💡 Теперь вы понимаете, почему во втором уроке мы писали scanf("%d", &var)! Функция scanf принимает указатель int *, чтобы записать ввод пользователя прямо в вашу переменную в памяти!
