Урок 1: Введение в Си — Первая программа и компилятор

Язык Си (C) — это латинский алфавит компьютерной индустрии. Написанный в 1972 году Деннисом Ритчи в Bell Labs, он стал фундаментом современных операционных систем, баз данных и высокоуровневых языков. В этом уроке мы разберем, как код превращается в машинные нули и единицы, и напишем первую каноническую программу.

01. Зачем учить Си в XXI веке?

Сегодня существует множество языков с автоматической сборкой мусора и дружелюбным синтаксисом: Python, JavaScript, Go. Зачем же инженеры продолжают учить и использовать язык полувековой давности?

Архитектурная аналогия: Чертежи и фундамент
Если Python — это роскошный пентхаус с готовой мебелью и голосовым управлением, то Си — это железобетонный фундамент, водопроводные трубы и электрическая проводка в стенах. Вы можете жить в пентхаусе, не зная физики тока, но если вы хотите стать настоящим архитектором и понимать, почему программы работают быстро или тормозят — вам необходимо знать Си.

Вот где язык Си незаменим прямо сейчас:

  • Операционные системы: Ядро Linux (на котором работают 90% мировых серверов и Android), Windows NT и macOS X написаны преимущественно на Си.
  • Сам Python: Стандартный и самый популярный интерпретатор Python (CPython) целиком написан на Си. Когда вы вызываете быстрые библиотеки вроде NumPy или PyTorch — под капотом выполняется сверхбыстрый Си-код.
  • Базы данных: PostgreSQL, SQLite, Redis — критически важные хранилища данных, требующие предсказуемого расхода каждого байта памяти.
  • Встраиваемые системы (IoT) и микроконтроллеры: Бортовые компьютеры автомобилей, датчики «умного дома», медицинское оборудование и космические аппараты работают на чистом Си.

02. Компиляция против Интерпретации

Процессор компьютера (CPU) понимает исключительно последовательности электрических сигналов — машинный код (нули и единицы). Человек же пишет текст на понятном ему языке. Как преодолевается эта пропасть?

⚙️
Интерпретатор vs Компилятор: Синхронный переводчик против Издательства

В Python (интерпретация): Программа-интерпретатор читает исходный файл строка за строкой прямо во время запуска и на лету отдает инструкции процессору. Если на 1000-й строке опечатка — программа упадет только тогда, когда выполнение дойдет до нее.

В Си (компиляция): Специальная программа — компилятор (например, gcc или clang) — заранее берет весь файл целиком, тщательно проверяет все типы и синтаксис, оптимизирует код и превращает его в готовый исполняемый файл (.exe в Windows или бинарник в Linux). На целевом компьютере для запуска Си-программы не нужно устанавливать ничего лишнего!

4 стадии рождения Си-программы:

  1. Препроцессинг (Preprocessing): Обработка директив с решеткой (например, #include). Текст подключаемых библиотек вставляется в файл.
  2. Компиляция (Compilation): Преобразование чистого Си-кода в инструкции ассемблера под конкретную архитектуру процессора (x86_64, ARM).
  3. Ассемблирование (Assembly): Перевод ассемблерных мнемоник в машинный двоичный объектный код (.o / .obj).
  4. Компоновка (Linking): Линковщик собирает ваши объектные файлы вместе со стандартной библиотекой языка (libc) в единый исполняемый бинарник.

03. Анатомия первой программы «Hello, World!»

Взгляните на классическую программу на Си. В отличие от Python, где достаточно написать print("Привет"), в Си требуется строгая структура:

c • main.c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
Терминал:
Hello, World!

Разберем каждую строку под микроскопом:

1. #include <stdio.h>

В самом Си нет встроенных ключевых слов для вывода текста на экран или чтения с клавиатуры. Все эти возможности предоставляются библиотеками. Директива #include приказывает препроцессору найти заголовочный файл stdio.h (расшифровывается как Standard Input / Output header) и подключить его. Именно там находится объявление функции printf.

2. int main(void) — Главная входная дверь

Любая программа на Си обязана содержать ровно одну функцию с именем main. С неё операционная система начинает выполнение программы:

  • int (integer — целое число): тип данных, который функция вернет обратно операционной системе после завершения.
  • main: строго зарезервированное имя точки входа.
  • (void): явное указание на то, что функция не принимает входных аргументов при запуске.

3. Фигурные скобки { ... }

Если в Python границы блоков определяются отступами (4 пробела), то в Си тело функции строго ограничивается открывающей фигурной скобкой { и закрывающей }. Отступы нужны только для удобства чтения программистом.

4. printf("Hello, World!\n");

printf (от англ. print formatted — форматированная печать) выводит строку на экран.

  • Символ \n: это специальная escape-последовательность, обозначающая перенос каретки на новую строку. Без него следующий вывод «прилипнет» к предыдущему тексту вплотную.
  • Точка с запятой ;: категорически обязательна в конце каждой инструкции! Для компилятора точка с запятой — это знак точки в предложении. Если забыть ;, компилятор не поймет, где кончается команда, и откажется собирать бинарник.

5. return 0;

Инструкция завершает работу функции main и передает число 0 операционной системе. В стандартах POSIX и Windows код 0 означает: «Программа выполнена успешно, ошибок не произошло». Любое ненулевое число (1, -1, 42) сигнализирует ОС о коде ошибки.
