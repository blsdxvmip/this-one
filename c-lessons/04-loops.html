Урок 4: Циклы и статические массивы

Компьютеры созданы для выполнения монотонной работы со скоростью миллиардов операций в секунду. В этом уроке мы научимся автоматизировать повторения с помощью трех видов циклов и объединять переменные в непрерывные цепочки памяти — статические массивы. А также узнаем, почему выход за границы массива в Си опаснее, чем в любом другом языке.

01. Три вида циклов в языке Си

В Си есть три базовые циклические конструкции: for, while и do-while. Каждая идеально подходит под свои сценарии.

1. Классический цикл for — Точный счетчик

Заголовок цикла for делится точками с запятой на три строго разграниченных секции:

c • for_loop.c
for (int i = 0; i < 5; i++) {
    printf("Итерация номер: %d\n", i);
}
  • int i = 0; — Инициализация: выполняется ровно один раз перед стартом цикла. Создается переменная-счетчик.
  • i < 5; — Условие продолжения: проверяется перед каждым витком. Если истинно (не 0), тело цикла выполняется. Если ложно (0), цикл немедленно завершается.
  • i++ — Инкремент: выполняется в самом конце каждого витка (увеличивает i на единицу).

2. Цикл while — До наступления события

Используется, когда точное количество повторений заранее неизвестно (например, ожидание корректного ввода пароля): 

int health = 100;
while (health > 0) {
    printf("Боец в строю! Здоровье: %d%%\n", health);
    health -= 25; // Уменьшаем здоровье, чтобы не зациклиться навечно
}

3. Цикл do-while — Гарантированный первый шаг

Главное отличие: проверка условия происходит после выполнения тела цикла. Код внутри гарантированно выполнится хотя бы один раз: 

int pin;
do {
    printf("Введите секретный PIN (1234): ");
    scanf("%d", &pin);
} while (pin != 1234); // Не забудьте точку с запятой в конце do-while!
printf("Доступ разрешен!\n");

02. Статические массивы в памяти компьютера

Если вам нужно сохранить не одну оценку, а оценки 30 учеников, создавать 30 отдельных переменных неудобно. Для этого существуют массивы (arrays).

Массив в Си — это непрерывная последовательность ячеек памяти одинакового типа.

c • array_demo.c
#include <stdio.h>

int main(void) {
    // Объявляем массив из 5 целых чисел и сразу инициализируем его
    int scores[5] = {95, 82, 67, 100, 74};

    // Нумерация элементов строго с нуля: от 0 до 4!
    printf("Первый элемент: %d\n", scores[0]);
    printf("Последний элемент: %d\n", scores[4]);

    return 0;
}
Аналогия: Вагоны скоростного поезда
Массив в Си устроен как железнодорожный состав. Вагоны жестко сцеплены друг с другом без зазоров. Если первый вагон [0] находится на перроне с координатой 100, а длина вагона sizeof(int) = 4 байта, то адрес вагона [1] математически равен 100 + 4 = 104, вагона [2] — 108, и так далее. Процессору не нужно искать элементы — он мгновенно вычисляет их физический адрес в оперативной памяти с помощью простой формулы умножения!

03. Главная угроза безопасности: Выход за границы массива

В языках вроде Python или Java при попытке обратиться к несуществующему элементу arr[10] виртуальная машина немедленно остановит программу и выбросит IndexError.

В языке Си проверка границ массива (bounds checking) полностью отсутствует ради абсолютной скорости работы!

🚨
Переполнение буфера (Buffer Overflow) и Undefined Behavior

Если вы объявили массив int arr[5];, то допустимые индексы — только 0, 1, 2, 3, 4.

Что произойдет, если написать arr[5] = 999;? Компилятор не выдаст ошибку! Процессор просто возьмет адрес начала массива, отступит в памяти 5 * 4 = 20 байт и запишет число 999 туда, где лежат соседние переменные вашей программы или системный адрес возврата из функции!

  • Утечка и порча данных: соседние переменные внезапно поменяют свои значения на мусор.
  • Segmentation fault: если вы попали в защищенную память ядра ОС, программа немедленно упадет.
  • Уязвимости безопасности: на переполнении буфера стека основаны 80% хакерских эксплойтов, позволяющих злоумышленникам захватить контроль над сервером.

Задание: Поиск максимума в массиве

Напишите программу на Си, которая:

  1. Создает массив из 6 целых чисел: int values[6] = {14, 52, 9, 87, 34, 61};.
  2. Объявляет переменную int max = values[0];.
  3. С помощью цикла for (int i = 1; i < 6; i++) проходит по всем элементам и, если values[i] > max, обновляет максимум.
  4. Выводит найденный максимум на экран: printf("Максимальное число: %d\n", max);.
